## 📚 Interview Challenges Included

This repository includes implementations of well-known interview-style problems:

- **Island Perimeter**  
  Compute the perimeter of an island represented in a grid.

- **Lockboxes**  
  Determine whether all boxes can be opened using the available keys.

- **Log Parsing**  
  Parse HTTP logs and output aggregated statistics.

- **Making Change**  
  Calculate the minimum number of coins required to reach a given amount.

- **Minimum Operations**  
  Determine the minimum number of operations needed using copy/paste logic.

- **N Queens**  
  Place *N* queens on a chessboard so that none attack each other.

- **Pascal’s Triangle**  
  Generate Pascal’s triangle up to *n* rows.

- **Prime Game**  
  Determine the winner of a prime-number-based game.

- **Rotate 2D Matrix**  
  Rotate a matrix 90 degrees clockwise **in place**.

- **UTF-8 Validation**  
  Validate whether a sequence of integers represents valid UTF-8 encoding.

- **Star Wars API**  
  Interact with the SWAPI to retrieve and process character information.
